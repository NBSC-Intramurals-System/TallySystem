# NBSC Intramurals Tally System

The NBSC Intramurals Tally System is a digital platform designed to automate scoring, calculate standings, and publish real-time leaderboards during annual Intramural Games. 

Automated Scoring -> Replaces paper tally sheets to prevent manual calculation errors across events.

Real-Time Standings -> Updates overall team rankings, medal counts, and point totals instantly for judges, organizers, and students. 

Secure Access -> Features role-based permissions for tabulators and committee members to input, verify, and audit event results.
